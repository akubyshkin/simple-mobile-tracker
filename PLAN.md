# TraceDay — план разработки

Приложение Android для записи дневного GPS-трека, синхронизации с Google Drive / Яндекс Диск, просмотра трека на карте и импорта чужих треков по ссылке.

## Решения

| Область | Решение |
|---|---|
| Язык | Kotlin, minSdk 26, targetSdk 34 |
| UI | Jetpack Compose, Material 3, тёмная тема, навигация + нижняя панель |
| Карта | osmdroid (OpenStreetMap, без API-ключа) |
| Хранение | Room (локальные точки треков, 7 дней), DataStore (настройки) |
| Геолокация | FusedLocationProvider: GPS (высокая точность) или сеть/вышки (экономный режим), foreground service с типом `location` |
| Облако | Абстракция `CloudClient`: Google Drive REST (OAuth через Google Sign-In + GoogleAuthUtil), Яндекс Диск REST (OAuth 2.0 через Custom Tabs, redirect `traceday://oauth2`) |
| Формат файла | JSONL: одна точка на строку `{"t":ts,"lat":..,"lon":..,"acc":..,"p":..}`, файл на день `track-YYYY-MM-DD.jsonl` |
| Синхронизация | WorkManager (периодическая + ручная), флаг `uploaded` у точек, стратегия «перезапись файла дня по локальным данным», backoff, устойчивость к потере сети |
| Хранение данных | 7 дней: локальная очистка + удаление старых файлов в облаке (CleanupWorker) |
| Шаринг | Публичная ссылка на файл дня (Drive permissions / Disk publish) |
| Импорт | Парсинг ссылки (Drive / Диск / raw URL) → скачивание → разбор JSONL → наложение на карту |
| Тесты | JUnit + Robolectric: кодек JSONL, парсер ссылок, расчёт статистики, границы дня, retention, DAO |
