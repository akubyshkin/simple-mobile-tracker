# TraceDay

Android-приложение для записи дневного трека перемещений: фоновая фиксация GPS-координат каждые N секунд, хранение локально, синхронизация файлами-днями в Google Drive или на Яндекс Диск, просмотр трека на карте, обмен своими треками по ссылке и наложение чужих треков.

## Возможности

- Фоновая запись координат (foreground-сервис с типом `location`, интервал 15 с – 5 мин)
- Два режима точности: GPS (высокая точность) или сеть/вышки/wifi (экономный, через FusedLocationProvider)
- Автосинхронизация в облако каждые 30 минут + ручная по кнопке; файл на день `track-YYYY-MM-DD.jsonl` (JSONL)
- Google Drive (вход через аккаунт Google, scope `drive.file`) и Яндекс Диск (OAuth 2.0 через Chrome Custom Tabs)
- Просмотр трека на карте OpenStreetMap: выбор дня (7 последних), фильтр «последние 1/3/6 ч», статистика (дистанция, время, точки)
- Публикация ссылки на трек дня («Поделиться днём») — файлу выдаётся публичный доступ, ссылка копируется в буфер
- Импорт чужих треков по ссылке (Google Drive, Яндекс Диск, любой URL на `.jsonl`) с наложением на карту, включение/выключение и удаление слоёв
- Устойчивость: офлайн-очередь точек в Room, повторные попытки WorkManager с backoff, авто-refresh токенов, переживание потери сети/перезагрузки (опция «возобновлять после перезагрузки»)
- Хранение данных 7 дней: локальная очистка и удаление старых файлов в облаке (CleanupWorker раз в сутки)

## Стек

Kotlin 2.0 · Jetpack Compose (Material 3, тёмная тема) · Hilt · Room · DataStore · WorkManager · Retrofit/OkHttp · kotlinx.serialization · osmdroid · Google Play services (location, auth)

## Требования

- JDK 17+ (проверено на 21)
- Android SDK 34 (compileSdk/targetSdk 34, minSdk 26)
- Android Studio (Koala и новее) или чистый Gradle 8.9 (wrapper уже в проекте)

## Сборка

```bash
./gradlew assembleDebug
adb install app/build/outputs/apk/debug/app-debug.apk
```

Release: задать подпись в `app/build.gradle.kts` (`signingConfigs`) и выполнить `./gradlew assembleRelease`. Release по умолчанию собирается с R8 (сжатие + обфускация + shrink resources, ~2.6 МБ против ~22 МБ debug); отключить: `./gradlew assembleRelease -Ptraceday.minify=false`. Правила — `app/proguard-rules.pro`.

Через Android Studio: Open → каталог проекта → Run ▶.

## Настройка облаков

Ключи читаются из `local.properties` (не коммитится; создайте рядом с `settings.gradle.kts`):

```properties
sdk.dir=/path/to/android-sdk
yandex.clientId=<ID вашего приложения на oauth.yandex.ru>
```

**Яндекс Диск**
1. Создайте приложение на https://oauth.yandex.ru/client/new
2. Платформы → «Веб-сервисы»: Redirect URI = `traceday://oauth2`
3. Доступы → Яндекс Диск REST API: `cloud_api_3.disk` (чтение и запись)
4. ID приложения (`ClientID`) положите в `local.properties` как `yandex.clientId`

**Google Drive**
1. По умолчанию вход идёт через системный аккаунт Google и scope `drive.file` — отдельный ключ не нужен
2. Если получаете ошибку `invalid audience`/`invalid_client`: в Google Cloud Console создайте OAuth-клиент (тип Android, package `app.traceday`, SHA-1 дебаг-хранилища) и включите Google Drive API

## Как пользоваться

1. При первом запуске разрешите геолокацию (и уведомления на Android 13+)
2. Большая круглая кнопка ▶ на карте — начать/остановить запись (появится постоянное уведомление, остановка прямо из него)
3. Настройки → Облако → выберите провайдера → «Подключить» и авторизуйтесь
4. Точки копятся локально и выгружаются воркером; статус виден на карте («Ожидает синхронизации: N»). Папка в облаке настраивается: Настройки → Облако → «Путь к папке TraceDay» (пусто — корень; вложенные папки создаются автоматически, папка приложения всегда называется `TraceDay`)
5. «Поделиться днём» (иконка Share) — публичная ссылка на файл дня в буфере обмена
6. Импорт: кнопка со ссылкой на карте → вставьте ссылку чужого трека → он появится чипом внизу карты (тап — показать/скрыть, × — удалить)
7. Включённые чужие треки обновляются автоматически, пока открыта карта (не чаще раза в 10 минут); ушли с карты — обновлений нет
8. История — список дней с дистанцией/временем, тап открывает день на карте

## Ограничения и заметки

- Интервал записи применяется при следующем старте записи
- Файл дня перезаписывается целиком по локальным данным (стратегия local-first, приложение — единственный писатель)
- Doze/экономия батареи могут прореживать фиксации; на отдельных прошивках добавьте приложение в исключения автозапуска
- Определение по вышкам оператора — это экономный режим fused-провайдера (сеть+wifi+вышки), отдельной работы с TelephonyManager нет
- Токены хранятся в EncryptedSharedPreferences, локальная БД не шифруется (нет чувствительных данных, кроме координат)

```
└── ui/         # Compose: карта, история, настройки
```
